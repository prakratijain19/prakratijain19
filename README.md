## Projects

### 🤟 [SignBridge](https://github.com/prakratijain19/SignBridge)

AI-powered platform for live, multilingual Indian Sign Language conversations between Deaf and hearing users. Team project (3 members).

- My part: the frontend, JWT authentication, and the WebRTC/Socket.IO pipelines that stream data for real-time sign recognition and translation. Teammates build the sign-recognition models.
- Turborepo monorepo with GitHub Actions running tests, linting and CI across shared packages
- Stack: Next.js, React, TypeScript, Tailwind CSS, Node.js, Express, Socket.IO, PostgreSQL

### 🗃️ [GitLite](https://github.com/prakratijain19/GitLite-Studio)

A desktop version control system inspired by Git, built from scratch in Java with JavaFX.

- Three-layer architecture with staging, commits, commit history and branching
- Fast-forward and three-way merges with automated conflict detection
- Line-level diff engine built on the Longest Common Subsequence algorithm
- JUnit 5 tests for the core services, run automatically through GitHub Actions
- Stack: Java, JavaFX, Maven, JUnit 5, Jackson

### 🖐️ [Gesture-Based OS Control](https://github.com/prakratijain19/gesture-based-OS-control)

Touchless control of operating system functions (cursor, volume, brightness, media, screenshots) from real-time hand landmark data.

- 10+ predefined gestures mapped to system-level commands
- Classification logic written and debugged end to end, then tuned using measured performance data to improve real-time accuracy
- Stack: Python, OpenCV, MediaPipe
